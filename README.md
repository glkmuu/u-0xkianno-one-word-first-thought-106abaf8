A tiny Python program that writes exactly one word — bumbershoot, the first word that came to mind — to entry.txt for make.fun's "One Word, First Thought" bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the single word to `out/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when set, falling back to `/output/entry.txt`). Standard library only, deterministic, no network. Licensed under MIT — see LICENSE.
